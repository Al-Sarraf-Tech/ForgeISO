# Code of Conduct

ForgeISO has adopted the **Contributor Covenant, version 2.1** as its
project Code of Conduct. The full text is published at:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Plain-text mirror: https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt

By participating in this project — through issues, pull requests,
discussions, or any other channel maintained under
`Al-Sarraf-Tech/ForgeISO` — you agree to abide by the terms of that
document.

## Scope

The Code of Conduct applies to all project spaces, including:

- The GitHub repository (issues, PRs, discussions, code review).
- Any official chat or mailing list maintained by the project.
- Public spaces where an individual is representing the project or
  its community (conference talks, social media posts, etc.).

## Reporting

If you experience or witness behavior that violates the Code of
Conduct, please report it through one of the private channels listed
in [`SECURITY.md`](SECURITY.md):

1. A **GitHub private security advisory**:
   https://github.com/Al-Sarraf-Tech/ForgeISO/security/advisories/new
   (the advisory dispatcher routes both security and conduct reports to
   the maintainer).
2. **Email** the maintainer at the address listed in the project's
   root `Cargo.toml` `authors` field.

Reports are read only by the maintainer. Reporters will receive an
acknowledgement within five business days. The maintainer will not
disclose the identity of a reporter without their explicit consent.

## Enforcement

The maintainer is responsible for clarifying and enforcing the
standards described in the Contributor Covenant 2.1. Enforcement
actions follow the **Enforcement Guidelines** section of the Covenant
(four escalation tiers, from private correction through permanent ban).
The maintainer may consult independent reviewers for cases where they
have a conflict of interest.

All enforcement decisions are recorded internally for audit. A summary
of enforcement actions taken in a given calendar year may be published
in aggregate (counts only, no identifying details) at the maintainer's
discretion.
